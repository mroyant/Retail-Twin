# Scénario de démo (brouillon)

Durée cible : 3 minutes.

1. **Vidéo brute** (10 s) : une file de caisse filmée par une caméra de sécurité.
2. **Même vidéo avec les pistes** : boîtes et identifiants anonymes, sans aucun visage visible.
3. **Vue plan** : les points bougent sur le plan du magasin, avec les zones colorées.
4. **Alerte** : la file 1 dépasse le seuil, et « Ouvrir la caisse 3 — attente estimée 6 min » s'affiche.
5. **Vue manager** : heatmap de la journée et créneau de remplissage recommandé par allée.
6. **Vue fournisseur** : rapport de tête de gondole (passages, taux d'arrêt).

À préparer : la vidéo de test (licence vérifiée), les captures pour [assets/](assets/), et un plan B hors ligne si la démo live échoue.
